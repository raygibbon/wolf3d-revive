## Purpose and scope

This slice extracts Wolfenstein-specific display names (episode titles, difficulty labels, jukebox track names) from hardcoded arrays in `WL_MENU.c` and `WL_MAIN.c` into a SDL-free game-definition interface. The engine now consumes these names through `GameDefinition_*` accessors rather than compiled-in arrays.

## API

`src/engine/game_definition.h` defines `game_definition_t`:

- `episode_names` / `episode_count`
- `difficulty_names` / `difficulty_count`
- `jukebox_names` / `jukebox_count`

Accessors: `GameDefinition_EpisodeName`, `GameDefinition_DifficultyName`, `GameDefinition_JukeboxName`, and corresponding count functions. All return NULL or 0 for invalid/out-of-range input.

`GameDefinition_Default()` returns the original Wolf3D values. `GameDefinition_Valid()` validates all fields and names.

## Ownership rules

- Caller owns all arrays and strings.
- The engine stores `const` pointers; it does not copy or free.
- Default definition uses static arrays (process lifetime).
- Alternative definitions use caller-owned storage that must outlive the context.

## Review corrections

### 1. Consistent bounds in DrawNewSelection and HandleNewSelection

DrawNewSelection now caps episode count at 6 and difficulty count at 4 (matching HandleNewSelection). Invalid/out-of-range choices are clamped to 0 before cursor placement. NULL names are skipped.

### 2. Explicit game definition propagation

WL_MAIN.c uses `wl_game_definition` (a module-level static set via `WL_SetGameDefinition()`) with fallback to `GameDefinition_Default()`. main.c calls `WL_SetGameDefinition(GameContext_Definition(&game_ctx))` after context init. No uncontrolled mutable global state.

### 3. Jukebox as legacy adapter

The jukebox UI uses a fixed 3-bank x 6-track layout. `GameDefinition_JukeboxName()` is called with `jukebox_bank*6+i`; if the definition has fewer tracks, NULL is returned and an empty string is displayed. This is explicitly documented as a legacy adapter.

### 4. Updated acceptance

- `DrawNewSelection` and `HandleNewSelection` now use consistent bounds.
- Invalid/out-of-range choices handled safely.
- Game definition propagated through `WL_SetGameDefinition()`.
- Default Wolf3D behavior preserved.
- Jukebox 3x6 layout documented as legacy adapter.
