# R1.4 Legacy Content Isolation

**Revision:** R1.4

**Branch:** `feature/r1-4-legacy-content-isolation`

**Base commit:** `a82fc6f` (merge of R1.3 game-definitions work)

**Review date:** 23 November 2026 (Australia/Adelaide)

**Status:** **PASS** — all acceptance criteria verified after corrective pass.

## Objective

Isolate original Wolfenstein 3D WL6 resource assumptions behind an explicit,
testable legacy-content boundary while preserving 100% of existing behaviour.
Prepare for custom maps, mod assets and Workshop content without turning the
engine into a general-purpose rewrite.

## Changes Made

### New: `src/engine/legacy_content.h` and `src/engine/legacy_content.c`

Small native C adapter for selecting and validating the original WL6 content
source.

- `legacy_resource_t` enum identifying the eight WL6 resource types
  (VSWAP, MAPHEAD, GAMEMAPS, AUDIOHED, AUDIOT, VGADICT, VGAHEAD, VGAGRAPH).
- `legacy_content_t` struct owning an explicit directory path and eight
  filename slots. Plain value state, copyable, no mutable global state until
  validation.
- `LegacyContent_Default()` returns an immutable descriptor with the original
  WL6 filenames (directory empty until bound).
- `LegacyContent_Init(content, directory)` clears and initialises a
  caller-owned descriptor with default WL6 filenames and the supplied directory.
- `LegacyContent_SetResource(content, resource, filename)` replaces one
  filename (plain file names only).
- `LegacyContent_ResourceName(content, resource)` borrows the filename from the
  descriptor; with `content == NULL` it resolves the immutable WL6 default.
- `LegacyContent_Validate(content)` structural validation only.
- `LegacyContent_ValidateAssets(content, missing)` structural validation plus
  presence/readability of every resource; on first missing asset sets `*missing`.
- `LegacyContent_ErrorString(error)`.
- All error reporting is explicit; callers check return values.

### Modified: `src/engine/ID_CA.h` and `src/engine/ID_CA.c`

- Added `CA_StartupWithContent(const legacy_content_t *content)`.
- Added `CA_ResourceName(legacy_resource_t resource)`.
- `CA_Startup(const char *data_dir)` remains the backward-compatible WL6 entry
  point: it builds a default descriptor via `LegacyContent_Init` and delegates to
  `CA_StartupWithContent`.
- `CA_StartupWithContent` validates the descriptor, value-copies it into the
  engine-owned active content, probes required resources (VSWAP, GAMEMAPS,
  MAPHEAD, AUDIOHED, AUDIOT) and loads graphics (VGADICT, VGAHEAD, VGAGRAPH).
  Every failure path calls `CA_Shutdown()` and reports through `CA_Error()`.
- `CA_Shutdown()` clears the active content state and graphics handles.
- `CAL_SetupGrFile(const legacy_content_t *content)` reads VGADICT/VGAHEAD/VGAGRAPH
  filenames from the descriptor.

### Modified: `src/engine/ID_MAP.c`

- `CA_ReadMap()` resolves MAPHEAD/GAMEMAPS through `CA_ResourceName()`.

### Modified: `src/engine/ID_PM.c`

- `PM_Startup()` resolves VSWAP through `CA_ResourceName()`.

### Modified: `src/engine/ID_SD.c`

- `LoadAudio()` / `LoadDigi()` / `SD_SoundTicks()` resolve audio and digitized
  sample resources through `CA_ResourceName()`.

### Modified: `src/engine/WL_SAVE.c`

- Save identity hashing resolves MAPHEAD/GAMEMAPS/VSWAP through
  `CA_ResourceName()`.

### Modified: `src/engine/legacy_content.c`

- `LegacyContent_ResourceName(NULL, resource)` now resolves the immutable WL6
  default, matching its documented contract.

### Modified: `src/engine/ID_CA.c`

- Startup failures for missing/unreadable required resources now produce
  meaningful `CA_Error()` strings and leave the engine shut down cleanly.

### Modified: `tools/validation/run.py`

- R1.4 accepted milestone; focused jobs invoke real executable tests
  (`r14-legacy-content-adapter`, `r14-legacy-content-integration`).

## Public C API

```c
bool CA_StartupWithContent(const legacy_content_t *content);
bool CA_Startup(const char *data_dir);
const char *CA_ResourceName(legacy_resource_t resource);
void CA_Shutdown(void);
```

## Ownership and lifetime

- `CA_StartupWithContent` value-copies the caller descriptor into engine-owned
  state; the caller may release or mutate its descriptor afterwards.
- `CA_Shutdown` clears the active content and graphics handles; `CA_Startup` /
  `CA_StartupWithContent` re-init from scratch on each start.

## Resource filename mapping

- Graphics: `VGADICT.WL6`, `VGAHEAD.WL6`, `VGAGRAPH.WL6` by default, replaceable
  per resource through `LegacyContent_SetResource`
  (renamed in tests to `GFXDICT.WL6`, `GFXHEAD.WL6`, `GFXGRAPH.WL6`).
- Map: `MAPHEAD.WL6`, `GAMEMAPS.WL6`. Audio: `AUDIOHED.WL6`, `AUDIOT.WL6`.
  Digitized: `VSWAP.WL6`.
- No hardcoded filename opens remain on descriptor-configured paths; the only
  remaining original-name literals are immutable defaults and defensive fallbacks.

## Synthetic fixture design

- `tests/game_fixtures.py` (`game_files`) generates valid synthetic WL6 archives
  (Huffman graphics via the balanced test dictionary, Carmack-expanded maps,
  OPL2/digitized audio metadata, page-file VSWAP).
- Integration harness receives `<original_dir> <renamed_dir> <scratch_dir>` and
  generates missing/invalid asset fixtures inside the scratch directory.

## Production loader functions invoked by tests

- `CA_StartupWithContent`, `CA_Startup`, `CA_Shutdown`, `CA_ResourceName`,
  `LegacyContent_*`, `CA_CacheScreen`, `CA_CacheGrChunk`, `CA_ConvertRGBA`,
  `VL_SetPalette`.
